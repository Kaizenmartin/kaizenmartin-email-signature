KAIZEN MARTIN – GITHUB PAGES EMAIL SIGNATURE

Upload the CONTENTS of this folder to the root of the GitHub repository:
- index.html
- assets/

Then enable GitHub Pages:
Settings -> Pages -> Deploy from a branch -> main -> /(root)

IMPORTANT:
This index.html intentionally uses relative asset paths so the GitHub Pages preview works
regardless of your GitHub username.

Once GitHub Pages gives you the final public URL, the Gmail version should be regenerated
with absolute https://... image URLs before copying it into Gmail. This makes the signature
reliable after it leaves the GitHub page.
